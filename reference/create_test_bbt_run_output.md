# Get an example output of [`bbt_run`](https://docs.ropensci.org/babette/reference/bbt_run.md) or [`bbt_run_from_model`](https://docs.ropensci.org/babette/reference/bbt_run_from_model.md).

This output is used in testing.

## Usage

``` r
create_test_bbt_run_output()
```

## Value

the same results as
[`bbt_run`](https://docs.ropensci.org/babette/reference/bbt_run.md) or
[`bbt_run_from_model`](https://docs.ropensci.org/babette/reference/bbt_run_from_model.md)
